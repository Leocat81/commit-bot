# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-10-26

### Added

- Generate Conventional Commits messages from staged git changes
- OpenAI-compatible LLM integration with configurable model and API endpoint (DeepSeek by default)
- Support for staged, unstaged and untracked diffs
- Configurable output language, maximum diff size and custom prompt
- Source Control title bar action for one-click generation
