# Changelog

All notable changes to this project will be documented in this file.

## [0.1.1] - 2026-10-26

### Changed

- Describe the extension as model-agnostic: works with any OpenAI-compatible LLM, with DeepSeek as the default
- Update Marketplace keywords, setting descriptions and runtime error messages accordingly
- Add a usage screenshot to the top of the README

## [0.1.0] - 2026-10-26

### Added

- Generate Conventional Commits messages from staged git changes
- OpenAI-compatible LLM integration with configurable model and API endpoint (DeepSeek by default)
- Support for staged, unstaged and untracked diffs
- Configurable output language, maximum diff size and custom prompt
- Source Control title bar action for one-click generation
